## 3. 直接修正清单

### 3.1 `08-重构蓝图.md`

- §4.2：`status` 可恢复性改为只接受 `complete`/`partial`；补 `obb→apk_obb`；`parts[]` 注明预留字段。
- §5：Commit 摘要注明 `lib` 软链仅 `internal_data`；SELinux 改为 `restorecon -RF`，明确 v1 的 `-F` 是非递归观测；
  v1 仅 uid 回退探测，SELinux 不猜父目录。
- §6：特权路径白名单补 `/data/user_de*`、`/data/media/*/Android/{data,obb,media}`、
  `/sdcard/Android/{data,obb,media}`、`.toolkit-staging-*`/`.toolkit-bak-*`；
  签名校验拆成“自身防重打包（告警）”与“备份/目标包一致性（fatal）”。
- §10：`restorecon -F` → `restorecon -RF`。

### 3.2 `09-格式v2规范.md`

- §3.2.4：v2 优先 `restorecon -RF`；v1 的 `-F` 仅作观测。
- §3.2.7：增加保留 kind 处理规则（`unsupported` / `E_FORMAT_UNKNOWN`）。
- §4.1：修正备份/恢复顺序“相反”的表述。
- §5.3：v1 适配的 `status` 改为 complete/partial/failed 三态，0 个可用 part → `failed`；
  `sha256=null` 仅限适配器内存对象。
- §5.6：`migrate` 必须重新哈希，schema 要求非 null。

### 3.3 `10-恢复状态机与错误码.md`

- §2.2/§3：Install 失败按 commit 前/后区分 `target_untouched` / `installed_data_old`；
  Cleanup 明确 journal 最后删。
- §4：失败矩阵按 Install 前/后、Commit/Verify 事件态与回滚终态拆分；Prepare/Extract 清理失败 → `staging_only`。
- §5.2：`lib` 软链仅 `internal_data`；`internal_device_protected` 只 chown/restorecon。
- §5.3：Rollback 写 `rolledBackKinds[]`，Recovery 断点续回滚。
- §5.4：`restorecon -RF` 统一；明确 v1 的 `-F` 是非递归观测。
- §6.2：journal 增加 `rolledBackKinds[]`；`paths.current` 必须在第一次 `mv target bak` 前写入；
  `installed=true` 在 install-commit 后立即写；staging 可由 `restoreId` 确定性推导；
  Cleanup 先删产物、最后删 journal。
- §6.3：Recovery 处理 Install commit 窗口、Rollback 断点、staging 孤儿。
- §7.2：保留 kind `external_media`/`external_files` 未定义形状 → `unsupported`。
- §8.1：增加 7 个 `dataState` 的语义表。
- §8.2：增加 `E_USAGE`；逐行补齐 E 码 dataState；W 表增加统一规则。
- §9：增加 T41（Rollback 中途崩溃）、T42（Install commit 后崩溃）。

### 3.4 `assets/format-v2.schema.json`

- `backupId`：收窄为三种合法形态（v2 / v1 适配 / v1 迁移）。
- `parts[].file`：basename 收紧；按 `kind` 强制前缀（7 个 kind）。
- `parts[].level`：`compression=zstd` 必填且为 1–19；其它 compression 必须为 null/省略。
- `status=partial`：`parts` 至少 1 项。
- `origin.format=v1`：要求 `layout`/`metadataPath`/`sourceKey`，并校验 `layout` 枚举。
- `label`/`note`：禁止控制字符。
- 条件子 schema 补显式 `"type"`，Ajv `strict:true` 无警告。

## 6. 验证记录

### 6.1 Schema（Ajv 2020-12 + ajv-formats）

- `ajv` 8 + `ajv-formats` 3；`validateFormats=true`；`strict:true` 编译**无警告**。
- 22 个用例全部按预期：示例、v1 null 身份、v2 null 身份（失败）、in_progress、
  complete/in_progress 的 `finishedAt`、partial 空 parts（失败）、kind/file 前缀（失败）、
  zstd 缺/空 level（失败）、非 zstd 带 level（失败）、level 越界（失败）、
  backupId（失败）、路径穿越（失败）、非 tar 文件名（失败）、控制字符（失败）、
  大写 sha256（失败）、v1 origin 缺 sourceKey（失败）、保留 kind（通过）。
