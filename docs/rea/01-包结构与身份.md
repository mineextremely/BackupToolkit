# 01 · 包结构与身份

## 1. 文件级事实

| 项 | 值 |
|---|---|
| 文件名 | `BackupToolkit v1.1.1.apk` |
| 大小 | 3,373,888 B（≈3.22 MiB） |
| ZIP entry 数 | 93 |
| DEX | **仅 1 个** `classes.dex`（992,780 B） |
| `resources.arsc` | 26,600 B（资源极度精简） |
| `AndroidManifest.xml` | 4,288 B（二进制） |
| native lib 目录 | **无 `lib/`** —— 所有原生件都以 zip 形式放 `assets/` |
| 构建工具 | `androidGradlePluginVersion=8.2.1`（`META-INF/com/android/build/gradle/app-metadata.properties`） |

## 2. Manifest 全貌

```xml
<manifest package="r2ixzp.toolkit"
          android:compileSdkVersion="34" android:compileSdkVersionCodename="14">

  <uses-permission android:name="android.permission.INTERACT_ACROSS_USERS"/>

  <application android:appComponentFactory="androidx.core.app.CoreComponentFactory"
               android:extractNativeLibs="true"
               android:icon="@android:drawable/sym_def_app_icon"
               android:label="@string/AppName"
               android:name="r2ixzp.toolkit.MyApplication"
               android:theme="@style/AppTheme">
    Activity  SplashActivity            (LAUNCHER, exported)
    Activity  ui.Main.MainActivity
    Activity  ui.App.AppInfoActivity            label=应用信息
    Activity  ui.App.AppBackupRestoreActivity
    Activity  ui.SettingsActivity               label=设置
    Activity  ui.AboutActivity
    Activity  ui.File.FileSelectActivity
    Activity  ui.File.FileBackupRestoreActivity
    Activity  ui.RunCmdActivity                 label=运行
    Activity  ui.CrashActivity   (process=":crash", singleTask, excludeFromRecents)
    Activity  ui.LogsActivity
  </application>
</manifest>
```

要点（后续文档会展开）：

1. **只有一个权限** `INTERACT_ACROSS_USERS`（跨用户查询包信息）。没有 `WRITE_EXTERNAL_STORAGE`、没有 `MANAGE_EXTERNAL_STORAGE`、没有 `FOREGROUND_SERVICE`。
2. **没有声明任何 Service / Receiver / Provider**。这不是遗漏：libsu 的 `RootService` 是在 **root 守护进程**里通过 `app_process` 反射实例化的，不经过 AMS，无需 Manifest 注册（见 `02`）。
3. `android:icon` 指向 **Android 系统默认图标**，说明该包是「换包名 + 换签名 + 换应用名」的二次分发，未做图标资源替换。
4. `android:name="r2ixzp.toolkit.MyApplication"` 是个「壳 Application」，真正的初始化在 `attachBaseContext` 里换成另一个类（见 `02`）。
5. minSdk 21 / targetSdk 34（更新日志写明 v1.1.0 把 targetSdk 从 28 提到 34）。

## 3. 签名与来源判定

```
keytool -printcert -jarfile "BackupToolkit v1.1.1.apk"

Owner : CN=r2ixzp            Issuer: CN=r2ixzp      （自签名）
Serial: 1
Valid : 2021-10-05 → 3020-02-06
SHA1  : D2:FA:30:50:C5:5F:A8:0E:79:48:3E:19:7C:AA:41:81:04:B8:8E:3F
SHA256: DD:26:09:15:F8:61:94:CE:74:84:87:D7:1D:E7:8D:3F:DA:7C:1E:3B:7C:94:D0:DF:03:98:2C:05:70:77:08:6B
Alg   : SHA256withRSA，1024 位 RSA
```

判定依据（可复核）：

| 证据 | 说明 |
|---|---|
| 签名主体 `CN=r2ixzp` 与包名前缀 `r2ixzp.` 完全一致 | 分发者用自己的 key 重打包，并把包名改成 `r2ixzp.toolkit` |
| 应用图标是 `@android:drawable/sym_def_app_icon` | 换皮时未替换图标 |
| 资源 `values/strings.xml` 只有约 140 条、全中文、含「作者在线乞讨」赞助文案 | 由第三方维护者重写/裁掉了原项目资源 |
| `res/raw/change_log.txt` 从 `v1.0.0` 起全中文记录，含「光速虚拟机」「炼妖壶」「vmos」等本土化适配 | 这是**分发者自己的迭代史**，不是原上游 |
| 代码里内嵌了**当前证书**的 SHA-256 常量（见 `06`） | 说明构建时已把校验值改成本人证书 —— 典型「重新签名后同步打补丁」 |
| `!app!.apk` 自备份文件名、备份根目录名 `Backups/BackupToolkit` | 与包名/应用名一并对齐 |

**结论**：这不是原始上游仓库的官方产物，而是**第三方基于某开源备份工具（同类实现见下）做的重签名分发版**；包名、签名、图标、文案、防篡改常量都被替换过。

> 关于「上游是谁」：目录结构（`AppBackup/<pkg>/`、`!BackupInfo!<pkg>.json`、`!icon!<pkg>`、`assets/bin/<abi>.zip{busybox,zstd,toolkit}`、`root_shrc.sh`、三档 `apk/user/data` 选项、`RunCmdActivity/LogsActivity/CrashActivity` 组件名）与公开项目 **XayahSuSuSu/DataBackup** 的实现风格高度一致；但 dex 中**不含** `com.xayah.databackup`、`databackup`、`xayah` 任何字符串，且类/包名被整体 R8 重命名，无法用字符串直接坐实。**此条为推断**，重构时不建议依赖它（本文档集合已足够从零实现，见 `08`）。

## 4. assets 与原生组件

```
assets/
  main.jar                      3,632 B  → 内含 classes.dex (6,652 B) = libsu root server
  bin/arm64-v8a.zip           572,524 B  → busybox / toolkit / zstd
  bin/armeabi-v7a.zip         647,088 B  → 同上
  bin/x86_64.zip              732,709 B  → 同上
  bin/x86.zip                 676,445 B  → 同上
  dexopt/baseline.prof/.profm            → Baseline Profile（几乎为空，仅 528/51 B）
```

| 组件 | 版本/性质 | 用途 |
|---|---|---|
| `busybox` | **v1.36.1-Magisk**（2024-02-02 构建） | 提供 `tar / unzip / realpath / find / awk / grep / killall` 等 applet |
| `zstd` | **v1.5.5** | 压缩与解压；通过 `--format=` 同时支持 zstd/gzip/xz/lz4 |
| `toolkit` | 自研 ELF，~5 KB，只导出 `st_info` | 打印文件 size / uid（`stat()` + `printf("%ld")`），弥补精简 busybox 缺 `stat` |
| `main.jar` 内 `classes.dex` | libsu 的 `com.topjohnwu.superuser.internal.RootServerMain` + `IRootServiceManager` 存根 | root 守护进程入口（`app_process` 的 CLASSPATH） |

`toolkit` 的字符串常量只有 `st_info`、`stat`、`printf`、`%ld`，可断定它是「取 inode 元信息」的最小工具；shell 侧用法为：

```sh
STI='toolkit st_info'
$STI "$apk" s   # → 文件字节数（给 pm install -S 用）
$STI "$dir" u   # → 目录 owner uid（恢复时 chown 用）
```

## 5. 依赖库指纹（全部被 R8 混淆，按特征识别）

| 库 | 混淆后位置 | 识别依据 | 版本 |
|---|---|---|---|
| **libsu**（topjohnwu） | 包 `Activity` / `Intent` / `File` / `String` / `Service` | `com.topjohnwu.superuser.DAEMON_MODE`、`IFileSystemService`、`IRootServiceManager`、`--mount-master`、`Runtime.exec("su","--mount-master")`、`libsu-<pkg>` | 5.x（含 RootService + FileSystemService，默认 timeout 20s） |
| **fastjson2**（Alibaba） | 包 `com.alibaba.fastjson2`（类名同样被洗） | `JSONReader.Feature.SupportClassForName`、`NotWriteDefaultValue`、`IgnoreNonFieldGetter` | 2.x |
| **AndroidX** | `androidx.*` | 见下表 version 文件 | core 1.7.0 / recyclerview 1.3.2 / swiperefreshlayout 1.1.0 / lifecycle 2.3.1 / customview 1.0.0 / versionedparcelable 1.1.1 / interpolator 1.0.0 / annotation-experimental 1.1.0 / core-ktx 1.5.0（仅为资源残留）/ arch core-runtime 2.1.0 |
| **Kotlin stdlib** | —— | dex 内**查不到** `kotlin/jvm/internal/Intrinsics`、`kotlin/Metadata`；只在 `unknown/kotlin/*.kotlin_builtins` 留有资源残留 | 不存在（说明业务代码是 **Java**） |

未使用：`androidx.work`（无任何后台调度）、`androidx.room`、`okhttp`、`magisk` 相关 API —— 与 Dex 字符串计数一致（计数均为 0）。

## 6. 代码规模

jadx 共处理 **480 个类**，其中应用自有代码仅 **16 个类**（`r2ixzp.toolkit.*`），其余为库 + 混淆后的「业务逻辑包」：

```
r2ixzp.toolkit.*            16 类   UI 层 + 偏好枚举
c.*                         12 类   备份/恢复任务编排、应用备份信息模型
b.*                          9 类   列表适配器、应用列表加载器
p029super.* / p030switch.*  54 类   列表项、对话框、菜单回调等 UI 辅助
p004class.*                  4 类   ★ root 服务实现（IRootManager / IBackupManager）
p032this.*                  10 类   ★ AIDL 客户端存根
p005const.*                  1 类   带字符串解密的 Service 基类
p009else.*                   2 类   真正的 Application + 全局上下文/偏好
p003catch.*                  2 类   错误日志、通用工具（含 fastjson 全局配置）
p033throw.*                  5 类   Kotlin 风格工具类合集（exec 封装、用户句柄、路径深度…）
Activity/Intent/File/String/Service  ≈130 类   libsu（含 AIDL、RootService、FileSystemService）
androidx.*                  ≈ 18 类（大量被裁）
com.alibaba.fastjson2.*     ≈279 类
```

结论：**业务代码量很小（估计 3–5 kLOC Java），复杂度几乎全在 shell 引擎和跨进程权限边界上**。这对重构是好消息 —— 可复刻面清晰。

## 7. 资源与主题

- 布局 22 个（`activity_main`、`activity_app_backup_restore`、`activity_app_info`、`activity_cmd`、`activity_crash`、`activity_file_select`、`activity_log`、`item_app`、`item_backup`、`item_file` 等）。
- 主题色 `values/values-night/values-v22/…/values-v31` 多套 —— 与更新日志「优化界面主题」对应；**未使用 AppCompat/Material**，全部走 `android.app.*` + 系统 `AlertDialog/Preference`，因此没有 `appcompat` 依赖。
- 设置页是原生 `PreferenceScreen`（`res/xml/pref_setting.xml`、`pref_about.xml`）。
